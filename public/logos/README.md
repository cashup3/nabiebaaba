# Client Logos

## How to Add Logos

1. **Download logos** for each company listed below
2. **Save them** in this folder (`public/logos/`) with the exact filenames shown
3. **Supported formats**: PNG, SVG, JPG, WEBP
4. **Recommended size**: 400x400px or larger (square format works best)

## Required Logo Files

Place the following logo files in this directory:

- `canada-film-equipment.png` (or .svg)
- `ontario-camera.png` (or .svg)
- `strada-xr.png` (or .svg)
- `b-camera.png` (or .svg)
- `location-a.png` (or .svg)
- `rumiversal.png` (or .svg)
- `warner-brothers.png` (or .svg)
- `def-jam.png` (or .svg)
- `epic-records.png` (or .svg)
- `97-collective.png` (or .svg)

## Tips for Finding Logos

1. **Company websites**: Check the company's official website, usually in the footer or press/media section
2. **Logo databases**: 
   - [Logos World](https://logos-world.net/)
   - [Brandfetch](https://brandfetch.com/)
   - [SeekLogo](https://seeklogo.com/)
3. **Google Images**: Search "[Company Name] logo transparent png"
4. **Contact companies**: Reach out directly for high-resolution brand assets

## Image Requirements

- **Format**: PNG (transparent background preferred) or SVG
- **Size**: Minimum 400x400px, square format recommended
- **Background**: Transparent or white (will be converted to black/white in the slider)
- **Quality**: High resolution for crisp display

## Fallback

If a logo file is missing, the component will automatically show the company's initials as a fallback.
