# Audio Files

Place your background music file here.

**Supported formats:**
- `.mp3` (recommended)
- `.wav`
- `.ogg`
- `.m4a`

**File name:**
- `background-music.mp3` (or update the path in `components/Navbar/MusicButton.jsx`)

**Recommended settings:**
- Keep file size reasonable (under 5MB for web)
- Use MP3 format for best compatibility
- Consider looping-friendly tracks
